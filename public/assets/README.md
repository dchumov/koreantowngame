# Korea Town PNG 에셋

## 파일 목록

다음 PNG 파일을 `public/assets/`에 넣어야 합니다.

1. `bg-town-tile.png` — 지도 배경용 seamless tile
2. `building-dorm.png` — 기숙사
3. `building-store.png` — 편의점
4. `building-cafe.png` — 카페
5. `building-school.png` — 학교
6. `player-down.png`, `player-up.png`, `player-left.png`, `player-right.png` — 플레이어 4방향
7. `npc-yuna.png` — 유나 스프라이트 또는 스프라이트시트

## PNG를 어디서 가져오나

이 채팅의 이전 메시지에 접근할 수 있다면, 거기에서 generate_image로 생성된 이미지를 다운로드하면 됩니다.

그렇지 않다면 `nanobanana-asset-plan.md`의 프롬프트를 Nano Banana / Raphael AI에 넣어 생성하면 됩니다.

## 권장 크기

- 배경: 512×512 또는 1024×1024 수준의 seamless tile
- 건물: 대략 256×256
- 캐릭터: 한 포즈당 대략 32×32 또는 스프라이트시트 기준 128×256 정도
